# ETF 改造第二步：真实模型生成与恢复验证

## 当前结果

2026-10-20 使用当前执行环境已有的 AIsa 网关凭据，通过
`https://api.aisa.one/v1/chat/completions` 调用其当时目录内可用的
`deepseek-v4.1-flash`。凭据仅在执行进程内使用，未写入仓库、日志或 GitHub
Secrets。此验证不表示定时工作流已具备同一凭据或已接入模型。

沿用第一步的不可变正式运行材料，在 TIPS、GLD/GLDM、Hawkes 电力市场研究
三篇样本上进行三轮小规模试验，共9次实际生成请求。没有用人工改写冒充
模型原始输出，没有修改正式成刊、选文、行情、发送或已发送历史。

| 试验 | 真实结果 | 输入 token | 输出 token（含推理） | 总 token |
|---|---|---:|---:|---:|
| 初版提示词，默认思考模式 | 两篇引用/数字检查拒绝；TIPS 输出被截断 | 7,875 | 8,347 | 16,222 |
| 收紧数字要求，显式关闭思考 | 两篇通过引用检查；TIPS 引用/数字拒绝 | 8,313 | 2,228 | 10,541 |
| 模型选择句子编号，程序复制原文 | 两篇通过引用检查；TIPS 数字依据仍不足 | 13,735 | 1,478 | 15,213 |
| 合计 | 9次生成 | 29,923 | 12,053 | 41,976 |

数字来自提供方返回的 usage，不是独立 token 计数。第一轮共6,670个推理
token；后两轮均返回0个推理token。编号式引用使长文输入变大，因此不能
只根据输出减少推断总费用下降。回执没有可靠的逐请求美元扣费字段，本次
不把公开价目表估算当成已核实账单金额。

## 为什么尚不能切正式邮件

- TIPS：最新输出把“2004年前用因子模型估算”写进限定条件，但该条件
  所选引用不含2004年或该模型说明，继续拒绝。原始材料本身也已截断。
- Hawkes：第二轮虽通过机械检查，仍把 Quarter-Hourly 误译为“季度小时”，
  将 bid-ask spread 译成不够准确的“利差”。最新轮保留歧义术语，买卖价差
  翻译已改善，但一条限定条件把“未说明覆盖其他市场条件”的编辑判断放进
  作者限定条件，需要移到待核对问题。
- GLD/GLDM：最新轮数值与主要结论可对应留存材料，但税务段还应核清
  每条引用覆盖范围与适用人群；不能把文章的美国税务陈述当成用户香港
  税务结论。问题区还有重复或可直接从已采集内容回答的问题。

上述是本次对话对原始材料的编辑复核，不是独立金融事实核查，也不是盲测。
提示词修改使用了这三篇样本，不能用其结果声称整个信源集合的准确率。
机械通过的卡片仍为 `evidence_linked_pending_review`，未自动升级为已验证。

## 这一步的代码变化

1. 原文按句生成稳定的局部编号，保留完整句子，不做长度裁剪。模型返回
   `evidence_ids`，程序从原材料逐字复制引用，再执行原有证据校验。材料
   哈希仍绑定原文版本，陌生编号拒绝。离线导入仍支持第一步的显式引用格式。
2. 保留金额数字及原单位，禁止擅自改成“万/亿”；英文日期可保留原样。
   仅把 LaTeX 百分号转义作为显示语法归一，不放宽数字、正负号或单位检查。
3. 增加可选 `--thinking disabled`，只有显式指定才向支持该参数的提供方
   发送。未给其他提供方设置默认参数；该开关已通过本次网关实际响应验证。
4. 自动读取输出目录中的 `responses.json`，结合 `generation.json` 断点
   恢复。单篇失败留在对照稿中，不阻止后续文章；失败不自动重试。模型、
   提示词、输出上限或思考设置变化时要求独立目录，防止混用试验结果。
5. 成功响应、解析失败及 usage 均可追查；异常只记类型，避免把提供方响应
   或敏感请求信息写进错误日志。HTML每个原文URL最多显示25个英文词的
   引用片段，完整证据仍保留在本地回执中；显示限额不改变校验所用材料。

## 运行与验收

在配置 `ETF_CARD_API_URL`、`ETF_CARD_MODEL`、`ETF_CARD_API_KEY` 的执行环境：

```powershell
python scripts/etf_content_cards.py generate --materials sample-materials.json --out-dir artifacts-model-check --max-calls 3 --max-input-chars 40000 --max-output-tokens 2400 --thinking disabled
```

第二次使用相同命令会读取断点记录，完成或失败过的材料不会盲目再次请求。
更换模型或提示词请使用新输出目录。输出为待审影子稿，非发信输入文件。
输入/输出和请求数限制不是美元硬预算，也不意味着可以跳过账单与定价核对。

62项针对性测试、15个子测试通过，涵盖断点恢复、失败后继续、禁止混用
配置、编号到原文的确定性映射和预览引用限额。沿用第一步的Windows临时
目录运行器兼容处理；测试断言和产品行为未绕过。第一步提交的 GitHub
automation-tests、microcap、icim 三项远端回归均已成功，本步远端结果另查
本步提交对应的检查记录。

下一步应完善逐条语义复核、术语歧义处理、缺证据任务和留出样本验证，
之后再接正式中文摘要函数。不能因单一模型两次同意就宣称事实已经核实。
